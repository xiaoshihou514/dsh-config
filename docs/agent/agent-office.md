# 智能体办公室

Agent Teams 的 3D 可视化，以「办公室模式」呈现：侧边栏左下角「办公室」开启（唯一入口），办公室里「← 返回对话界面」关闭；开关、正在看的团队、对话栏宽度存在 localStorage（`dsh-config:office`），刷新后直接回到办公室。

办公室挂在 `shell.overlay`，默认铺满窗口：左栏是组长动态（当前动作、待办进度、最近派活）/ 队伍卡片 / 成员详情，中间 3D 场景（组长头顶不冒气泡），顶部 HUD。点成员的「打开对话」切换当前会话，覆盖层收成左侧成员栏、3D 场景隐藏，右边是原生对话（原生中央列靠左内边距让出成员栏）；Esc 或「回到办公室」收起对话。项目显示名用文件夹对应工作区的标题（项目面板里 ✎ 改名，原生侧边栏同步），没有时用文件夹名，3D 墙上的招牌跟着变。顶栏「项目」面板：已有团队（每个文件夹一个，取最近组建的那个；同一文件夹重新组队后，记住的旧团队自动换成新团队，新团队在招到第一个成员后出现；记住的组长会话被删除时连续 3 次找不到就忘掉，回到默认选择）与「组建新团队」——列出还没有团队的工作区或「选择其他文件夹…」，点击后在该文件夹新开会话并发送项目经理提示词（`TEAM_PROMPT`）。界面全部自绘（无原生 select），沿用原生 `--dsw-*` 配色，带游戏 HUD 风格。

## 结构

| 文件 | 职责 |
|---|---|
| `src/agent-office.ts` | 宿主插件：`GET /dsh-config/office?lead=`（需 `x-dsh-config: agent-office`，带 ETag）、`POST /dsh-config/office/override`（手动指定岗位 / 人设 / 档位，存 `$DSH_HOME/dsh-config/office-overrides.json`）、`GET /dsh-config/office/teams`（组建过团队的会话列表，按最近活跃排序）、`GET /dsh-config/office/scene.js`（ETag 协商缓存） |
| `src/office/derive.ts` | 纯推导：会话事件 → 成员活动、当前动作、交流、任务（有单测） |
| `src/office/classify.ts` | 模型 → 厂商 / 档位，名字 + 描述 → 岗位；改档位规则看 `FAST_PATTERNS` / `FLAGSHIP_PATTERNS` |
| `src/office-scene/` | three.js 场景（独立 ESM `lib/office-scene.js`，打开弹窗时才加载） |
| `src/client/office/` | 办公室模式：`OfficeShell.tsx`（覆盖层、HUD、项目面板、队伍 / 详情 / 交流）、`store.ts`（持久状态）、`styles.ts`（样式） |

## 数据来源

- 名册：Lead 会话的 `team/member`；任务：`team/task`，没有则用 Lead 的 `todo/write`。
- 交流：接收方日志里的 `agent-message`（成员消息）、`subagent-settled`（完工汇报）、子会话首条用户消息（招募）、Lead 的用户消息（你的指令）。
- 活动：`tool/call` / `tool/result` / `assistant/message`；已加载会话读内存，未加载的读持久化存储（按存储版本缓存）。
- 是否在跑：以浏览器会话状态为准，宿主推导（已加载且有未结束步骤）兜底。

## 角色

- 角色图鉴：点击角色进入细看（放大、自动旋转，可切正 / 斜侧 / 侧 / 背角度与站立、走路、打字、思考、等待、沟通、休息动作，← → 切换，Esc 返回）。
- 未知模型（兜帽旅人）的三视图由 `scripts/draw-unknown-persona.py` 绘制为 `assets/personas/other.png`，与其他各家同一规格、同一流程；`人设/体素/other.png` 存在时优先用它。`personas.ts` 的调色只给网格兜底角色用。
- 表情贴片的嘴色由各家肤色推算（暖褐粉），不用固定的红紫色。
- 快速档是缩小 0.8 的简装版（短发、短裙），刘海带黄色闪电发夹。
- 岗位：左臂袖章与胸章颜色、右手道具、工位摆设（后端服务器机箱、测试虫罐、审查稿纸…）；组长头顶金星、独立玻璃办公室。

## 自查

- 有三视图的厂商（`../人设/体素/<厂商>.png`）：`scripts/voxelize-personas.py` 按 DeepSeek 图的像素格（14px）切网格，生成 `src/office-scene/sprites.generated.ts`；`sprite-character.ts` 逐行推算截面（每段宽取正视图、深取侧视图的超椭圆，窄段按自身宽度收深度），按侧视图挖空；颜色按平滑法线分区（朝前取正视图、朝后取背视图、朝侧取侧视图），侧视图颜色只采用正 / 背视图附近出现过的（否则换成最接近的），头部前段侧面用相邻鬓发色。关节：头、上身、下身、左右腿（手臂未拆）。换图后重跑脚本再构建。
- 没有三视图的厂商（目前只有未知模型）回退到网格角色（`anime.ts`）。岗位道具与星标等小件是体素（`props.ts`）。

## 布局与动画

- 圆桌布局：组长坐圆心面朝前方，组员面朝圆心围一圈（前方 ±30° 留进出缺口，座位从后排往前排填；超过 8 人用前半圈的第二圈）。
- 像素画角色的头 / 上身 / 下身是一张蒙皮网格，三根骨骼驱动：脖子以上跟头；脖子以下的背后与两侧（长发所在）从髋到脖子逐渐过渡到跟头；胸前跟上身；髋部上下身平滑过渡。转头时长发顺着弯，不按颜色区分头发，任何角度都没有接缝。像素画角色转头幅度减半。另配可动手臂（肩宽按脸宽定、可用 `ARM_TWEAK` 逐家微调，前后只看肩膀那几行躯干的前沿；泡泡袖肩头往身体里接一段，颜色取立绘肩部袖色，手用脸部肤色）。
- 表情：`sprite-character.ts` 的 `FACE_SPEC` 手工标注每家正视图的眼睛 / 嘴位置，表情以贴片覆盖（闭眼、笑眼、半睁、张嘴、小嘴、微笑），`pose()` 按状态切换并自动眨眼。
- 动作：打字（命令行更快）、阅读、书写、托腮思考、抱臂等待（偶尔看表）、边说边比划、工位伸懒腰、沙发喝咖啡、站立挥手、收到消息跳一下并惊讶。

## 加载

- 浏览器在按钮出现后空闲时预取场景脚本；脚本带 ETag，未重建时 304。
- 体素用整数键；工位几何按岗位缓存；休息区等装饰在首帧后空闲时再搭。

## 场景环境与信息

- 固定机位（`index.ts` 的 `fitOffice`）：办公室不能旋转 / 平移 / 缩放，镜头角度固定，按画布大小把房间（含墙厚、底座、墙顶上方留给头顶信息的空间）的包围盒投到画面里求外接框，居中并取能完整放下的缩放；画布尺寸变化时重算。轨道控制只在角色图鉴里启用。成员面板的「在场景中定位」不动镜头，只让选中光环放大闪几下。
- 房间 20×16（`ROOM`），后墙、左墙是整面墙（左墙靠前是大门，正对主过道），朝镜头的前墙、右墙按剖面图只留矮墙，底下一块地板底座，四周是天空。
- 休息区（`LOUNGE`）在后墙右侧、紧挨圆桌：沙发背靠后墙，坐着的人面朝镜头；站着喝咖啡的人只在茶几左右两侧；咖啡柜台在右后角，不挡人。书架移到左后角。
- 寻路（`nav.ts`）：房间划成 0.25 的格子，工位、沙发、茶几、柜台、书架、盆栽、落地灯的水平包围盒按人的半径外扩成障碍（贴地的地毯不算），8 邻域 A*（不许斜擦墙角）后按视线拉直成少量拐点。座位在家具包围盒里，用「入口点」进出：椅子从椅背一侧、沙发从正前方，站位就是本身（都再就近挪到空地）。路线 = 出座位到入口 → A* → 走进目标座位；目标一变就从当前位置重新寻路（走到一半也会掉头）；工位增减、陈设搭好时重建格子并让正在走的人重新规划；寻不到路时退回预设路线。行走起步加速、到站减速；互相靠近时往旁边（统一偏右）让一点，让完仍在空地上才挪。
- 环境按本地时间切换（`environment.ts`）：早晨（5–10 点）、正午（10–16:30）、傍晚（16:30–19:30）、夜晚，四周天空（容器背景，夜里有星星）、阳光（月光）方向与颜色、窗外景色（天空 + 城市剪影的画，傍晚和夜里亮灯）随之变化（每分钟检查）。傍晚起开灯：后墙、左墙的壁灯与沙发旁落地灯亮起并带光晕，三个室内点光源加暖色半球光把房间照亮。
- 醒目提醒（与浏览器桌面通知 `TurnNotify` 同一类时机，但在办公室里看得见）：快照里每个成员带 `lastTurn`（最近一轮结束的时间、是否成功；之后又开了新一轮就没有）。当组长这一轮已结束、之后你没再发过指令、整个团队都停下来（还有人在干活时组长会被汇报自动叫醒，不打扰你）、且这次还没看过，持续 2 秒后：组长走到桌前面朝镜头频繁挥手、蹦一下（出错时低头垂手），头顶浮一个不被遮挡的大「!」（汇报为金色、出错为红色，带描边与光晕），脚下光圈扩散；HUD 顶部弹出横幅「组长汇报完毕，在等你回复」/「组长这一轮出错停下了」，可「查看汇报」（打开组长对话）或关掉；左栏组长动态同步显示。打开组长对话、关掉横幅、或对话本来就开着组长会话，都记为已看过（按组长记在 localStorage `dsh-config:office-ack`，刷新后仍记得）。
- 未读红点：左栏每个成员卡（和组长动态）的对话按钮上，某人最近一轮结束（说完一段话）晚于你上次打开他的对话就亮红点，「队伍」标题旁显示几人未读；组长有醒目提醒时也算未读。每人在 localStorage `dsh-config:office-reads` 记 `{ seen, latest }`：latest 是见过的最近一轮结束时间（新开一轮后快照里没有 `lastTurn`，所以自己记住），打开对话、或对话正开着这个人时把 seen 拉到 latest；第一次见到某人以当时为基线，旧消息不算未读。
- 角色头顶的名牌与气泡只在鼠标悬停或选中时显示（离开后保留 0.6 秒，方便点名牌）。墙上不再挂待办白板（左栏「组长动态」里有）。
- 信件飞行时每帧追踪收件人当前位置，人走开了也能送到。

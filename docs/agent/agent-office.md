# 智能体办公室

Agent Teams 的 3D 可视化，占满整个窗口（可再切浏览器全屏）。入口：侧边栏底部「办公室」（默认最近活跃的团队）与会话头部「办公室」按钮（打开当前团队）；顶栏「项目」面板：上半是已有团队（每个文件夹只保留最近活跃的一个），下半是「组建新团队」——列出还没有团队的工作区，或「选择其他文件夹…」；点击后在该文件夹新开会话、发送项目经理提示词（`TEAM_PROMPT`，面板里可查看），办公室直接切到新团队。

## 结构

| 文件 | 职责 |
|---|---|
| `src/agent-office.ts` | 宿主插件：`GET /dsh-config/office?lead=`（需 `x-dsh-config: agent-office`，带 ETag）、`POST /dsh-config/office/override`（手动指定岗位 / 人设 / 档位，存 `$DSH_HOME/dsh-config/office-overrides.json`）、`GET /dsh-config/office/teams`（组建过团队的会话列表，按最近活跃排序）、`GET /dsh-config/office/scene.js`（ETag 协商缓存） |
| `src/office/derive.ts` | 纯推导：会话事件 → 成员活动、当前动作、交流、任务（有单测） |
| `src/office/classify.ts` | 模型 → 厂商 / 档位，名字 + 描述 → 岗位；改档位规则看 `FAST_PATTERNS` / `FLAGSHIP_PATTERNS` |
| `src/office-scene/` | three.js 场景（独立 ESM `lib/office-scene.js`，打开弹窗时才加载） |
| `src/client/OfficeAction.tsx` | 头部按钮、弹窗、成员详情与交流动态面板 |

## 数据来源

- 名册：Lead 会话的 `team/member`；任务：`team/task`，没有则用 Lead 的 `todo/write`。
- 交流：接收方日志里的 `agent-message`（成员消息）、`subagent-settled`（完工汇报）、子会话首条用户消息（招募）、Lead 的用户消息（你的指令）。
- 活动：`tool/call` / `tool/result` / `assistant/message`；已加载会话读内存，未加载的读持久化存储（按存储版本缓存）。
- 是否在跑：以浏览器会话状态为准，宿主推导（已加载且有未结束步骤）兜底。

## 角色

- 角色图鉴：点击角色进入细看（放大、自动旋转，可切正 / 斜侧 / 侧 / 背角度与站立、走路、打字、思考、等待、沟通、休息动作，← → 切换，Esc 返回）。
- 未知模型（兜帽旅人）的三视图由 `scripts/draw-unknown-persona.py` 绘制为 `assets/personas/other.png`，与其他各家同一规格、同一流程；`人设/体素/other.png` 存在时优先用它。`personas.ts` 的调色只给网格兜底角色用。
- 表情贴片的嘴色由各家肤色推算（暖褐粉），不用固定的红紫色。
- 快速档是缩小 0.8 的简装版（短发、短裙），刘海带黄色闪电发夹。
- 岗位：左臂袖章与胸章颜色、右手道具、工位摆设（后端服务器机箱、测试虫罐、审查稿纸…）；组长头顶金星、独立玻璃办公室。

## 自查

- 有三视图的厂商（`../人设/体素/<厂商>.png`）：`scripts/voxelize-personas.py` 按 DeepSeek 图的像素格（14px）切网格，生成 `src/office-scene/sprites.generated.ts`；`sprite-character.ts` 逐行推算截面（每段宽取正视图、深取侧视图的超椭圆，窄段按自身宽度收深度），按侧视图挖空；颜色按平滑法线分区（朝前取正视图、朝后取背视图、朝侧取侧视图），侧视图颜色只采用正 / 背视图附近出现过的（否则换成最接近的），头部前段侧面用相邻鬓发色。关节：头、上身、下身、左右腿（手臂未拆）。换图后重跑脚本再构建。
- 没有三视图的厂商（目前只有未知模型）回退到网格角色（`anime.ts`）。岗位道具与星标等小件是体素（`props.ts`）。

## 布局与动画

- 圆桌布局：组长坐圆心面朝前方，组员面朝圆心围一圈（前方 ±30° 留进出缺口，座位从后排往前排填；超过 8 人用前半圈的第二圈）。
- 像素画角色的头 / 上身 / 下身是一张蒙皮网格，三根骨骼驱动：脖子以上跟头；脖子以下的背后与两侧（长发所在）从髋到脖子逐渐过渡到跟头；胸前跟上身；髋部上下身平滑过渡。转头时长发顺着弯，不按颜色区分头发，任何角度都没有接缝。像素画角色转头幅度减半。另配可动手臂（肩宽按脸宽定、可用 `ARM_TWEAK` 逐家微调，前后只看肩膀那几行躯干的前沿；泡泡袖肩头往身体里接一段，颜色取立绘肩部袖色，手用脸部肤色）。
- 表情：`sprite-character.ts` 的 `FACE_SPEC` 手工标注每家正视图的眼睛 / 嘴位置，表情以贴片覆盖（闭眼、笑眼、半睁、张嘴、小嘴、微笑），`pose()` 按状态切换并自动眨眼。
- 动作：打字（命令行更快）、阅读、书写、托腮思考、抱臂等待（偶尔看表）、边说边比划、工位伸懒腰、沙发喝咖啡、站立挥手、收到消息跳一下并惊讶。

## 加载

- 浏览器在按钮出现后空闲时预取场景脚本；脚本带 ETag，未重建时 304。
- 体素用整数键；工位几何按岗位缓存；休息区等装饰在首帧后空闲时再搭。
